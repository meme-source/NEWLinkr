# Design Presets

这个目录用于存放多个可切换的 `DESIGN.md` 预设。

当前项目刻意 **没有** 在根目录启用默认 `DESIGN.md`，因为你还不想现在定最终设计风格。

## 当前已准备的候选预设

- `claude.DESIGN.md`
- `linear.DESIGN.md`
- `notion.DESIGN.md`
- `vercel.DESIGN.md`

## 以后怎么用

当你之后说“调用设计预设”或“启用某个 DESIGN.md”时，应该先让 agent 给你弹出候选项，然后再做以下动作：

1. 让你从这几套预设里选择一个
2. 将选中的文件复制为项目根目录的 `DESIGN.md`
3. 后续页面和组件按当前激活的 `DESIGN.md` 执行

## 为什么不同时启用多个

`DESIGN.md` 是给 agent 读取的单一视觉规范。

如果项目根目录同时存在多套风格说明，agent 很容易混用：

- 配色体系互相冲突
- 圆角、排版、间距口径不一致
- 页面最终会变成拼接感很强的混合风格

所以保留多个候选是可以的，但根目录同一时刻只应有一个激活版本。
