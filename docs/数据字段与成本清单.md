# Linkr — 产品数据字段 × 数据来源 × 调用成本 清单

> 本文档回答三个问题:
> 1. 系统里**每一个**与博主 / 发现相关的数据字段是什么。
> 2. 每个字段**服务哪个功能点**。
> 3. 每个功能点**每调用一次的具体成本**。
>
> 字段定义以 `types/api.ts` 为准,并补充 `features/discovery/v3-view-models.ts`、
> `features/outreach/data/board-placements.ts`、`features/plugin/.../mock-posts.ts`
> 等视图层 / 功能层衍生字段。
>
> 爬取平台:**Apify**(TikTok actors)。AI 分析:**Claude API**。
> 价格基准:2026-05 Apify / Anthropic 公开定价。

## 第一部分 · 成本模型

### 1.1 Apify 单价(按结果计费 Pay-Per-Result)

| Actor | 用途 | 单价 |
| --- | --- | --- |
| `clockworks/tiktok-profile-scraper` | 博主主页 + 视频列表 | $0.005 / 结果 |
| `clockworks/tiktok-scraper` | 主页 / 话题 / 视频通用 | $0.005 / 结果 |
| `clockworks/tiktok-comments-scraper` | 视频评论采集 | $0.005 / 条评论 |
| `clockworks/tiktok-followers-scraper` | 粉丝列表采集 | $0.005 / 个粉丝 |
| `clockworks/tiktok-user-search-scraper` | 关键词搜博主 | $0.005 / 结果 |
| `clockworks/tiktok-video-scraper` | 单视频指标(追踪用) | $0.010 / 结果 |

> Apify 免费额度:每月 $5(约 1000 条结果)。
> 注:Apify **拿不到**粉丝画像(年龄/性别)、邮箱、互动率、中位播放 —— 见第三部分缺口说明。

### 1.3 功能点单次调用成本总表(核心)

> 下表是“每调用一次的具体成本”。字段表(第二部分)的“关联成本操作”列指向这里的 OP 编号。

| 编号 | 功能点 / 操作 | 构成 | 单次成本 | 说明 |
| --- | --- | --- | --- | --- |
| **OP-1** | 博主档案抓取(主页 + 近 30 条视频) | Apify profile scraper:1 主页 + 30 视频 ≈ 31 结果 × $0.005 | **≈ $0.15 / 博主** | 一切原始数据的入口 |
| **OP-2** | 内容标签 AI 分析(分类 / 话题 / 风格) | Haiku:输入 ~6k token + 输出 ~1k token | **≈ $0.01 / 博主** | 依赖 OP-1 已抓到文案 |
| **OP-3** | 受众深度画像(`audienceAnalysis` 整块) | 评论采集 1000 条 $5 + 粉丝采样 1000 个 $5 + Sonnet 推断 ~$0.2 | **≈ $10 / 博主** | 最贵操作;样本缩到 300+300 可降至 **≈ $3** |
| **OP-4** | 一次博主发现搜索(竞品 / 场景 / 爆款) | Sonnet 对 ~60 候选批量出 reasons/risks/score:输入 ~30k + 输出 ~9k | **≈ $0.25 / 次搜索** | **不含**候选池抓取(候选库为一次性建库成本) |
| **OP-5** | 找相似 / 找平替(一次) | 封面 embedding ~$0.001 + Sonnet 5 维打分 / 叙述 ~$0.13 | **≈ $0.15 / 次搜索** | 候选池已入库时;需现抓种子 +OP-1 |
| **OP-6** | 报价估算(`estimatedPrice` / CPM / CPE) | 纯计算公式 | **≈ $0**(可选 +Haiku $0.005 做行情校准) | 计算层,无外部调用 |
| **OP-7** | 建联邮件生成(个性化) | Haiku:输入 ~3k + 输出 ~0.6k | **≈ $0.01 / 封** | 个性化片段越多越贵 |
| **OP-8** | 投放数据刷新(`viewsTrend` / 投放卡指标) | Apify video scraper 重抓 1 视频 | **≈ $0.01 / 视频 / 次** | 每日刷新追踪 30 天 ≈ $0.30 / 视频 |
| **OP-9** | 邮箱 / 联系方式获取 | bioLink 已在 OP-1 内;邮箱需爬落地页或第三方联系人库 | **≈ $0.10–0.50 / 博主** | 命中率不稳定,视第三方而定 |
| **OP-10** | 单帖深度分析(插件:受众 / 水粉 / 互动) | 评论采集 ~500 条 $2.5 + Sonnet ~$0.05 | **≈ $2.5 / 帖** | 即 OP-3 的单视频缩小版 |
| **OP-11** | 产品→场景→可拍达人类型映射(场景解析) | Sonnet:输入产品描述 ~2k + 输出场景/类型 ~2k | **≈ $0.04 / 次解析** | 按产品一次性,结果可复用 |

### 1.4 典型业务流程成本(端到端示例)

| 流程 | 涉及操作 | 合计 |
| --- | --- | --- |
| 新博主入库(基础可用) | OP-1 + OP-2 + OP-6 | **≈ $0.16 / 博主** |
| 博主完整档案(含受众画像) | + OP-3 + OP-9 | **≈ $10.4 / 博主**(受众分析为成本主体) |
| 跑一次“找同行投过的”发现 | OP-4(候选库已存在) | **≈ $0.25 / 次** |
| 候选库首次建库(1000 博主) | OP-1 × 1000 + OP-2 × 1000 | **≈ $160**(一次性,后续增量) |
| 发现 1 个博主并发出建联 | OP-1 + OP-2 + OP-7 | **≈ $0.17 / 博主** |

> **成本结论**:受众画像(OP-3)是唯一的高单价操作,占单博主完整成本的 95%+。
> 产品上 `audienceAnalysis` 默认 `null`、需“解锁”后才分析,正是为了控制这块成本。
> 其余所有操作均为 $0.01–0.25 量级。

## 第四部分 · 三类数据归类总结

### ① 直接爬取(Apify) — 由 OP-1 / OP-8 / OP-10 提供

账号原始字段:`handle` `name` `avatar` `region` `followers`、累计获赞、作品数;
单帖原始字段:`recentPosts` 全部指标(`views/likes/comments/shares` 等)、`hashtags`、
`url`、`postedAt`、`music`;bio 外链(→ `socialLinks`)。
**约占全部字段 30%。** 投放趋势(`viewsTrend*`)需定时重复爬取。

### ② 已爬数据计算(纯规则,无 AI) — 多为 OP-1 后处理 / OP-6

`medianViews` `engagementRate` `recentActiveAt`、各 `*_band`、`peakViews`
`viralCount` `burstMultiple` `performance_ratio` `trendType`、CPM / CPE、
`vsCreatorBaseline`、`age17PlusShare`、雷达 `baseline`、`seed_coverage`。
**约占 25%。** 计算层成本 ≈ $0,放 `lib/scoring/`。

### ③ 需要 AI 分析(Claude) — OP-2 / OP-3 / OP-4 / OP-5 / OP-7 / OP-11

- **内容理解(OP-2)**:`category` `topics` `themes` `keywords` `style_tags`
  `brandMentions` `creatorType`。
- **受众画像(OP-3 / OP-10)**:`AudienceProfile` 整块 —— 性别 / 年龄 / 地区 / 兴趣 /
  `credibility` 全部子项、`fakeFans`。**这是 Apify 的最大缺口,也是最贵的一类。**
- **匹配打分(OP-4 / OP-5)**:各 `*_score` `matched_features` `reasons` `risks`
  `narrative` `tradeoffs` `evidence` `replicaConfidence` `fitScore` `repeatable`、
  `recommendedShootingStyle` / `angle`(“怎么拍”)。
- **场景映射(OP-11)**:`Scene` 全字段、`productSummary`、可拍达人类型。
- **建联文案(OP-7)**:`subject` `content` 及个性化分段。

**约占 25%。**

### ④ 系统 / 人工(与爬虫、AI 均无关)

`Collaboration` 全套、各时间线字段、`rating` `userTags` `favorited` `notes`
`method` `budget` `finalPrice`、`rateCard` `paymentTerms` `manualContactName`、
`Project` 字段、各请求参数 / chips / filters。**约占 20%,无外部调用成本。**
